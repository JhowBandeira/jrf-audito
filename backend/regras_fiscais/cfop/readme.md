# Módulo CFOP

Responsabilidade: interpretar o CFOP da operação.

O módulo deve responder:
- O CFOP é entrada?
- O CFOP é saída?
- O CFOP é serviço?
- O CFOP é devolução?
- O CFOP é transferência?
- O CFOP é remessa?
- O CFOP é retorno?

O módulo CFOP não calcula impostos.
Sua única responsabilidade é interpretar o CFOP.
