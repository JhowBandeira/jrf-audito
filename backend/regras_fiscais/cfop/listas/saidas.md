## Observação

Este arquivo apenas identifica se o CFOP é uma operação de saída.

Ele não define se a operação gera débito de ICMS.

O débito será analisado pelo módulo de ICMS, considerando:

- ICMS destacado;
- CST/CSOSN;
- devoluções de venda;
- isenções;
- suspensões;
- imunidades;
- serviços;
- demais regras fiscais.
