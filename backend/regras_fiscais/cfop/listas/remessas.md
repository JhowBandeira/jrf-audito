- O CFOP representa remessa?

Não. Assim como vimos na transferência, a lógica é a mesma: o CFOP de forma genérica não significa "remessa". Ele é o catálogo que classifica qualquer tipo de operação, e as remessas são apenas uma categoria dentro desse grande catálogo.

No universo fiscal, chamamos de "Remessa" aquelas operações onde a mercadoria circula, mas geralmente não há uma venda imediata ou a finalidade principal não é comercializar aquele item naquele momento (ex: enviar para conserto, para demonstração, para armazenagem, dar um brinde, etc.).

Para saber se a nota fiscal é uma remessa, você precisa olhar o código específico. A grande maioria dos CFOPs de remessa está concentrada nos grupos finais X.900 (Outras Saídas/Entradas).

Aqui estão os principais CFOPs que representam Remessas (com seus respectivos retornos):

1. Remessa para Conserto ou Reparo
5.915 / 6.915: Remessa de mercadoria ou bem para conserto ou reparo.

1.915 / 2.915: Entrada de mercadoria ou bem recebido para conserto ou reparo.

5.916 / 6.916: Retorno de mercadoria ou bem recebido para conserto ou reparo.

2. Remessa para Industrialização (Terceirização)
5.901 / 6.901: Remessa para industrialização por encomenda.

1.901 / 2.901: Entrada para industrialização por encomenda.

5.902 / 6.902: Retorno de mercadoria utilizada na industrialização por encomenda.

3. Remessa para Demonstração ou Mostruário
5.912 / 6.912: Remessa de mercadoria ou bem para demonstração.

1.912 / 2.912: Entrada de mercadoria ou bem recebido para demonstração.

5.928 / 6.928: Lançamento efetuado a título de remessa de mercadoria para operar como mostruário.

4. Remessa de Bonificação, Brinde ou Doação
5.910 / 6.910: Remessa em bonificação, doação ou brinde.

1.910 / 2.910: Entrada de bonificação, doação ou brinde (como quem recebe não vai devolver, é uma remessa que encerra a operação).

5. Remessa para Armazém Geral ou Depósito Fechado
5.905 / 6.905: Remessa para depósito fechado ou armazém geral.

1.905 / 2.905: Entrada de mercadoria recebida para depósito em depósito fechado ou armazém geral.

6. Remessa para Venda Fora do Estabelecimento (Venda Ambulante)
5.904 / 6.904: Remessa para venda fora do estabelecimento (quando o vendedor sai com a mercadoria no caminhão sem destinatário certo).

1.904 / 2.904: Retorno de remessa para venda fora do estabelecimento (o que o vendedor não conseguiu vender e voltou para a empresa).

💡 Resumo: Se a operação for apenas para "movimentar" a mercadoria por um motivo específico (conserto, demonstração, brinde, armazenagem) sem caracterizar uma venda tradicional, devolução ou transferência entre filiais, o CFOP utilizado será um código específico de Remessa (geralmente na faixa dos 900).
